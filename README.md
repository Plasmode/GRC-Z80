# GRC-Z80
Generic Retro Computer (GRC) is a modular system for 8-bit (and some 16-bit) processors of 1970's and 1980's.  GRC-Z80 is based on Z80 while shares common backplane, RAM/Flash, CPLD, CF disk, I/O and video boards

![sideview](grc_z80_3_22_22.jpg)

GRC-Z80 is based on the following GRC modules:
- [Z80 module](https://github.com/Plasmode/GRC/tree/main/Z80_module)
- [GRC backplane](https://github.com/Plasmode/GRC/tree/main/Backplane)
- [CPLD module](https://github.com/Plasmode/GRC/tree/main/CPLD_module)
- 512K [RAM/Flash module](https://github.com/Plasmode/GRC/tree/main/RAM_Flash_module)
- [Quad serial module](https://github.com/Plasmode/GRC/tree/main/Quad_serial_module)
- [VGA-PS2 module](https://github.com/Plasmode/GRC/tree/main/VGA_PS2_module)
- Housed in PacTec CM5-200 enclosure
